# Netflix Data Analysis

## Project Overview
This project analyses the Netflix Titles dataset using Python. It explores movies, TV shows, countries, release years, ratings, directors, actors, genres, and movie durations.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
- netflix_titles.csv

## Analysis Performed
- Dataset overview
- Data cleaning
- Movies vs TV Shows
- Top 10 Countries
- Year-wise release trend
- Top Directors
- Top Actors
- Genre analysis
- Rating analysis
- Duration analysis

## Key Insights
- Movies are more common than TV Shows.
- The United States has the highest number of Netflix titles.
- Netflix content increased rapidly after 2015.
- Drama and International Movies are the most common genres.
- Most movies are around 90–100 minutes long.
